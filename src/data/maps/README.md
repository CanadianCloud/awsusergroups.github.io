# Map source

`land.geojson.json` is the Natural Earth 1:110m land dataset, downloaded from the project maintained by Natural Earth coauthor Nathaniel Vaughn Kelso:

https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

The site's interactive map renders this bundled geometry with Leaflet instead of requesting third-party map tiles. It requires no API key, account, external tile endpoint, or recurring tile-service subscription. Locations and search filters come from the site's existing user group directory.
